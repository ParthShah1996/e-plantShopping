# e-plantShopping
This project (e-plantShopping) involves building a working shopping cart application for Paradise Nursery.
The following features are included,
- A Landing page with a button linking to the product listing page.
- A navigation bar with links to the landing, product listing, and shopping cart pages.
- A card for each plant that showcases the different plants along with their images, name, description, cost, and an **Add to Cart** button.
- Different sections of plants, such as "Aromatic Plants", "Medicinal Plants", etc.
- A cart page which displays the products in the cart.
- The cart will have a card for each type of plant. Each card will have a thumbnail, the unit cost, the cost of all the plants of that type, and buttons to increase and decrease the quantity, along with a **Delete** button.
- A Continue Shopping and Checkout buttons.
